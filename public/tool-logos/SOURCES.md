# Tool logo sources

- Playwright: https://playwright.dev/img/playwright-logo.svg (official project)
- Postman: https://cdn.simpleicons.org/postman (Simple Icons)
- Apache JMeter: https://cdn.simpleicons.org/apachejmeter (Simple Icons)
- MS Excel: https://cdn.jsdelivr.net/npm/simple-icons@11/icons/microsoftexcel.svg (Simple Icons v11, monochrome asset)
- Google Workspace: https://workspace.google.com/static/img/google-workspace-logo.svg (official Google asset)

Simple Icons assets are published under CC0: https://github.com/simple-icons/simple-icons/blob/develop/LICENSE.md

Dark theme variants:
- Excel: white monochrome rendering of the same Simple Icons v11 path; geometry unchanged.
- Google Workspace: official light-gray transparent PNG from https://knowledge.workspace.google.com/static/images/admin/google-workspace-wordmark-light-gray.png
